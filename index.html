Embodied Infrastructure Half-Life

What embodied agents should stop relying on

Tools, skills, and harnesses encode assumptions about what a model cannot yet do. Embodied Infrastructure Half-Life asks how the gain from a fixed support configuration, measured over the same model’s basic robot interface on the same tasks and budgets, decays as models improve, and when it has fallen to half.

Read the essay →
Research prototypeGitHub ↗

RoboExperience

Using experience to make robot agents better, in context. A read-only library of past demonstrations sits beside an episode-local memory of what just happened; both are retrieved into a frozen policy’s context under a fixed budget.

  • Experience retrieval
  • In-context learning
  • Robot memory
